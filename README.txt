CaptureForge Startup Tools

1. Put these BAT files in the SAME folder as CaptureForge.exe.
2. Double-click ENABLE_CAPTUREFORGE_STARTUP.bat.
3. CaptureForge will run automatically when you sign in to Windows.

To remove it later, run DISABLE_CAPTUREFORGE_STARTUP.bat.

No shortcut and no administrator permission are required.
